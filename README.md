# WATCHLOG

A C++ security log analysis engine designed to parse authentication events, identify suspicious activity, and support rule-based threat detection.

## Features

- Authentication log parsing
- Security event classification
- Password spray detection
- Detection engine
- Structured event processing
- Unit testing with GoogleTest

## Technologies

- C++20
- CMake
- Ninja
- nlohmann/json
- GoogleTest

## Architecture

The project separates log parsing, event processing, detection logic and testing into modular components.
